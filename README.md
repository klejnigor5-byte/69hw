# ДЗ 69.1 — Mongo Shell: studentDB

## Вимоги
- Встановлений MongoDB Server та MongoDB Shell (`mongosh`).
- MongoDB запущений локально або є доступ до вашого MongoDB deployment.

## Як виконати
У терміналі перейдіть до папки з файлом та запустіть:

```bash
mongosh < solution.js
```

Або відкрийте `mongosh` і виконуйте команди з `solution.js` по черзі.

## Що містить робота
1. Створення бази `studentDB` та колекції `assignments`.
2. Додавання п'яти документів.
3. Пошук студентів з балом вище 80.
4. Збільшення на 5 балів для Andrew, якщо його бал менше 85.
5. Видалення студента з найнижчим балом.
6. Виведення лише імен та балів через проекцію.
7. Необов'язкова агрегація середнього бала за предметом з фільтром `averageScore > 75`.
8. Необов'язковий унікальний індекс за `name` та перевірка через `explain("executionStats")`.

> Примітка: скрипт очищає `assignments` на початку, щоб повторний запуск давав передбачуваний результат. Не запускайте його на колекції з власними даними, які потрібно зберегти.
